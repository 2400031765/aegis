# Aegis AI

Aegis AI is an AI-powered emergency assistance and distress intelligence platform designed to help users during emergency situations.

## Features
- AI-powered distress analysis
- Emergency location support
- Safe places recommendation
- Voice assistance
- Risk assessment engine
- Real-time emergency workflows

## Tech Stack
- Python
- FastAPI
- React Native / TypeScript
- Google Gemini
- REST APIs

## Architecture
Frontend (React Native)
↓
FastAPI Backend
↓
AI Service Layer
↓
Gemini Provider
